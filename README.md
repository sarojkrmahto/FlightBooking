# FlightBooking

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 17.3.17.

## Installation

Run the following command to install the project dependencies:

```bash
npm install
```

## Running the Backend

Run the following command to start the backend server:

```bash
npm run backend
```

## Development Server

Run the following command to start the Angular development server:

```bash
ng serve 
```
Navigate to [http://localhost:4200/](http://localhost:4200/). The application will automatically reload when you modify the source files.


### Or ###

Run the following command to start the Angular development server and automatically open the application in your default browser:

```bash
ng serve --open
```
